## 傅里叶是什么？

先讲因果，再讲工具： 
- **先有定理（1807 傅里叶）**：任何信号都能拆成"一堆正弦之和"。
- **后有算法（1965 FFT）**：一个"算得飞快"的算法，让拆解能在计算机上跑。 
- 所以：**"能拆"是定理，FFT 只是"算得快"的工具。** 回顾01的种子：一个 f Hz 的正弦 = 一个每秒转 f 圈的点。于是： **任意波形 = 很多个不同转速的点在转圈，再叠加。** 傅里叶就是反过来问：有几个点在转？各转多快（频率）、多高（幅值）？

## 傅里叶作为一个工具箱，有什么工具？

把工具箱打开，分三层：

**① 两个核心工具（对应第 1 站的信号分类）：** 
	- **傅里叶级数**：拆**周期**信号 → 得到**离散谱**（钢琴键）。 
	- **傅里叶变换**：拆**非周期**信号 → 得到**连续谱**（小提琴滑音）。
	- 见"周期/离散谱/谐波"用级数；见"非周期/连续谱/脉冲"用变换。 
**② 工具的零配件（性质）：**
	- 奇偶虚实性、时间尺度、对称性……这些是"傅里叶变换的使用说明"，告诉你"时域里做了什么操作，频域里会对应怎么变"。 
	- （细节以后再补，现在先知道它们存在、属于"工具箱"，不是"非周期信号专属"。）
**③ 工具的例题（典型信号频谱）：** 
	- 矩形脉冲、δ 函数、正余弦……这些是"傅里叶变换算出来的标准答案"，方便你以后对答案、查表。 - （同上，先眼熟，细节以后补。）
## 傅里叶工具如何运用在信号分析上？

两个真实场景，看清傅里叶的用途： - **明牌（作业里）**：我先造了波，FFT 只是"对答案"。 - **暗牌（真实世界）**：拿到未知混合波（脑电/振动/声音），FFT 是唯一"透视镜"，读出里面有哪些频率。 **脑电节律（频域的真实应用 = 我的 attention 字段）：** | 节律 | 频率 | 何时强 | |---|---|---| | δ | 0.5~4 Hz | 深睡 | | θ | 4~8 Hz | 困倦、冥想 | | α | 8~13 Hz | 放松、闭眼 | | β | 13~30 Hz | 警觉、专注 | - 测"专注/放松" = 对脑电做 FFT → 看 α 和 β 谁的能量大。 - 我脑环的 `attention` 字段，就是厂商用这个频域方法算出来的。
