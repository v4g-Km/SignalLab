## 为什么从测试系统可以到信号数据流？

- 工程测量中可分为**静态测量**和**动态测量**。
	- 静态测量指的是不随时间变化的物理量。
	- 动态测量是指随时间变化的物理量的测量，是机械测试技术基础这本书主要的研究对象。
- 而我们从动态测量的概念"随时间变化的物理量"出发， 用"横轴为时间、纵轴为取值"的函数来**描述**它——这就是**时域描述**。 
- （注意一个常见误区：我们习惯把"信号"直接想象成"正弦波那样 周期起伏的形状"，但那只是周期信号的一种；信号还包括非周期信号、 随机信号，见 01 的信号分类部分。）
- 测量系统的实际过程就是由传感器接受信号，调理过后传入计算机去分析结果，做出反馈，这个过程其实就是信号数据流的过程。
- 由此，我们开始看数据流是怎么样的⬇️
## 数据流长什么样？

```
被测物理量 ──→ 传感器 ──→ ❗信号调理 ──→ 数字化(ADC) ──→ 计算机处理/决策（❗信号处理）
 (信号)       (翻译官)     (放大/滤波)    (模拟→数字)      (分析+判断)
 |--------------- 模拟域 ----------------｜----------数字域-------------
```

| 环节    | 教材定义          | 载体     |
| ----- | ------------- | ------ |
| 被测物理量 | 随时间变化的物理量     | 现实世界   |
| 传感器   | 物理量 → 电量翻译官   | 硬件（黑盒） |
| 信号调理  | ADC 前的模拟预处理   | 硬件（黑盒） |
| 数字化   | 模拟 → 数字       | 硬件（黑盒） |
| 处理/决策 | ADC 后的分析 + 判断 | **软件** |
#### 信号的一生：以脑环数据为例：
**场景**：你戴脑环，先静止 1 秒 → 头向右匀速转 2 秒 → 停。这条"角速度随时间变化"的曲线，就是**被测物理量**（一个连续的模拟信号）。

同一个"信息"（头在右转），在链上换了 5 种形态：

| 环节           | 信号长什么样                            | 具体数值例子                |
| ------------ | --------------------------------- | --------------------- |
| ① 被测物理量      | 角速度 gx(t)：连续曲线，静止=0，右转=+30°/s     | 30°/s                 |
| ② 传感器（陀螺仪）   | 电压 V = k·gx(t)，把角速度"翻译"成电压，k=灵敏度  | V = 0.05×30 = 1.5V    |
| ③ 信号调理       | 电压被**放大**，高频毛刺（手的微颤）被 RC 电路**洗掉** | 放大到约 3V，去掉抖动          |
| ④ ADC（采样+量化） | 连续电压被"咔嚓"成**离散数字串**，再归到最近台阶       | [2.98, 3.01, 2.99, …] |
| ⑤ 处理/决策      | 对数字串 EMA 滤波 → 减基线 → 阈值判断          | 输出"向右移"               |

**关键：前 3 个环节是**模拟信号**（连续光滑的电压波形），后 2 个环节是**数字信号**（一串离散数字）。"模拟域｜数字域"的分界，就是 ADC 那一刀切出来的——**同一个"头在右转"，左边还是连续的电压，右边就变成了一串数**。

>总讲信号数据流：一个物理量（头动、振动、力…）如何被**翻译成电信号、洗干净、数字化，最后变成一个可用的数字**，以及每个环节的仪器"性格"好不好。
#### ❗细节区分：信号调理 vs 信号处理：
看这一步发生在 ADC（模数转换）之前还是之后。

| 位置 | 域 | 信号形态 | 用什么做 | 教材章节 |
|------|-----|---------|---------|---------|
| ADC 之前 | 模拟域 | 连续电压 | 硬件电路 | 第 5 章 信号调理 |
| ADC 之后 | 数字域 | 数字序列 | 算法/代码 | 第 6 章 信号处理 |
所以：**调理 ≈ 模拟域 ≈ 硬件；处理 ≈ 数字域 ≈ 软件**。
#### ❗其中，调理和处理中都用到了**滤波**：软件滤波 vs 硬件滤波：

**滤波 = 洗信号**（就是"数据清洗"，只是对象是随时间变化的信号）。
区别只有两点：

|        | 软件滤波            | 硬件滤波             |
| ------ | --------------- | ---------------- |
| 用什么做   | 代码、公式           | 电阻电容等物理元件        |
| 作用在什么上 | 已数字化的数字串（ADC 后） | 未数字化的模拟电压（ADC 前） |

- 关键前提：**软件能滤波，是因为脑环已经把信号数字化了**；硬件滤波是因为信号当时还是模拟电压，只能靠电路碰。

## 从测量误差到概率论

既然我们有了数字化的信号，那么去研究数据结果和误差分析就是必不可少的了。
#### 为什么需要概率论？

同一个量，你测 5 次，得到 5 个略有不同的数。 这 5 个数的"散开程度"里藏着误差的规律——但你只看**一次**测量， 是看不出这个规律的。要看清误差，必须看**一堆**测量结果。 这一步，就把我们推进了概率统计。
而不仅仅止于测量技术中需要对结果进行多次分析，我们在获取信号和处理信号的过程，也是频繁需要用到概率论的知识进行数据分析的。这里略讲一下，后面会有更详细的专题。
